# Fronk documentation

New here? Read the [README](../README.md), then follow the
[installation guide](INSTALL.md).

These pages are written for you. The files in [`llm/`](llm/README.md) and
[`AGENTS.md`](../AGENTS.md) are written for your AI model: you hand them over when
you want its help, and you do not need to read them.
